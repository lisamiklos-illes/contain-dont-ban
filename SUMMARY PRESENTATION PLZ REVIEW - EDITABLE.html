OVERVIEW

Contain Don't Ban (CDB) is a tech stack and regulatory framework focused on LLMs that can make viruses

1

A new virus could literally kill us all

A self-replicating biological agent (e.g., a virus), once out in the world, can cause unprecedented levels of damage.

2

The likeliest cause is an accident.

A well-intentioned expert may accidentally create a highly dangerous self-replicating biological agent using an LLM.

3

Banning virus creation won't work

Banning the LLM capability of self-replicating biological agent creation is futile, humans will do what they want.

4

We can, however, control the rollout

CDB is a phased clearance framework and incentive framework to control virus-creating-LLM rollouts.

5

Controlled rollout is focused only on virus-creation capabilities

Contain Don't Ban is focused ONLY on an LLM's capacity to generate self-replicating DNA/RNA sequences.

What the gates measure

Confirmed virus-creating LLM misuse is too rare to count

If the true misuse rate is 1 in 100,000, a gate would need about:

300,000

users to see one confirmed case

5 million

users at a realistic 6% detection rate

So the rules run on proxy signals that fire often

Classifier flags

Cross-session cluster alerts

Red-team scores

Safeguard bypasses

Each gate publishes a power calculation: how many users and weeks before a rule could fire.

1 · Training chips

Developers who refuse continuous audits lose access to training chips. Exporting governments tie chip licences to certification.

Limit: bio-design models can be small, so chips alone are not enough.

2 · DNA synthesis

Synthesis vendors require the same bio login as the models. A design from an unregistered model is much harder to make real.

The physical step every design has to pass through.

Audits run continuously under a new WHO component that borrows accreditation, inspection and reporting from the IAEA.

Limits

The framework states its own limits

01

It raises the bar

The controls raise the resources and process complexity needed to create a self-replicating agent. They do not make it impossible.

02

Open weights are the hard case

Safeguards do not travel with the weights, so releasing weights requires full clearance, decided on pre-release trials.

03

Slow review has a condition

Open models trail the frontier by about 4 months (Epoch). Slowing the frontier only helps if weight release is gated too.

Partial protection is better than none.
