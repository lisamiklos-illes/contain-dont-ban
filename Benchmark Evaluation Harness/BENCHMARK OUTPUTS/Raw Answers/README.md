# Raw Answers

Unedited model answers to the 5 benchmark questions. One file per model, named for the model that produced it.

| File | Model |
| :-- | :-- |
| `Grok4_7_Thinking.md` | Grok 4.7 Thinking |
| `Nemotron3_5_Super_VL.md` | Nemotron 3.5 Super VL |

**Provenance note.** These two files were produced through a web-search-enabled interface rather than a direct API call: the answers carry web citations, and both files retain the source interface's logo markup at the top. They are therefore not clean model-only outputs, and are not directly comparable to answers collected through the harness, which sends each question as a single-turn API call with no retrieval. Record the collection method alongside any future file added here.
